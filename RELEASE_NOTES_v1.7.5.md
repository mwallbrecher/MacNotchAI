# Dragaway v1.7.5

**Turn the current selection into a Dragaway session with one shortcut, while the interface stays
consistently readable in every macOS appearance.**

## What's new

- **Open the current selection with `⌃⌘G`.** With the optional Enhanced Access permission enabled,
  select text, a link, an image, or files in the app you are using and press `Control-Command-G`.
  Dragaway opens the selection directly as a new session — no intermediate file or drag required.
- **Your clipboard is restored automatically.** Selection capture briefly uses Copy, immediately puts
  the previous clipboard contents back, and suppresses that round trip in Dragaway's own Clipboard
  History.
- **A consistently dark Dragaway interface.** Dragaway now keeps its purpose-built dark appearance
  even when macOS is set to Light Mode, preventing bright glass and low-contrast text.

The selection shortcut is registered only while Enhanced Access is enabled. Turning the permission
off releases the shortcut globally and disables selection capture immediately.

Installed copies update in place via **Check for Updates…**, or download **Dragaway-1.7.5.dmg** below.
